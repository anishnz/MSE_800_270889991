# MSE_800_270889991

Weekly Python coursework and class activities for MSE_800.

## Repository Structure

| Folder | Contents |
|---|---|
| [WK1](WK1) | Week 1 activities (BMI calculator) |
| [WK2](WK2) | Week 2 activities |
| [WK3](WK3) | Week 3 activities |
| [WK4](WK4) | Week 4 activities |
| [WK5](WK5) | Week 5 activities (comprehensions, loops, dictionaries, matrices) |
| [WK6](WK6) | Week 6 activities (ASCII art, blackjack game, employee access system, game, general practice) |
| [WK7](WK7) | Week 7 activities (OOP: inheritance types, polymorphism / payment system) |

Each activity folder contains:
- The Python source file(s) for the exercise, with inline comments explaining the code.
- A `README.md` describing the problem statement, approach, and how to run it.
- A `QUESTION_AND_ANSWER.txt` with the exercise question and a written answer/explanation.
- A `default.txt` placeholder in folders that currently have no exercise content yet.

## Requirements

- Python 3.x

## Running an Exercise

Each exercise is self-contained. Navigate to its folder and run its main script, e.g.:

```bash
cd WK7/ACT_7_3
python main.py
```
