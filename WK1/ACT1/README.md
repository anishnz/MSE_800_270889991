# BMI Calculator (Starter File)

## Problem Statement

This activity (WK1 / ACT1) is set up for a **BMI (Body Mass Index) Calculator**
exercise, as suggested by the folder name (`ACT1`) and the file name
(`bmi.py`). The eventual goal of this kind of exercise is typically to:

- Ask the user to enter their weight (in kilograms) and height (in metres).
- Calculate BMI using the standard formula:

  ```
  BMI = weight (kg) / (height (m) ** 2)
  ```

- Print the calculated BMI value, and optionally classify it into a
  category such as Underweight, Normal weight, Overweight, or Obese.

This is a common first step when starting a new Python file: verify the
